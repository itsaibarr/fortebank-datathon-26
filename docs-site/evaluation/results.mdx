## Read metrics correctly

`forte evaluate` aggregates **v1** completed client result directories. It reports TP/TN/FP/FN, failed positives/negatives, completed fraction, accuracy including failures, effective recall, false-positive rate, supplied-point proximity and client median/p95/max. Missing or source-mismatched results are rejected. Failure never becomes a negative.

- Accuracy including failures: `(TP + TN) / all planned known-label records`.
- Effective recall: `TP / all known positives`; failed positives reduce it.
- FPR: `FP / all known negatives`.
- Point proximity is a closest-timestamp diagnostic, not verified event matching or interval accuracy.

V2 abstentions need a separate protocol. Passing rich v2 JSON to the v1 evaluator is unsupported. Keep failures, abstentions and unrun cases visible.
