## Cleanup and evidence

Superseded pipelines, selectors, training infrastructure, dense/reranker paths and redundant provisioning/install frameworks were removed from the active source. Git history preserves tracked rollback. Unique original uncommitted work was preserved outside the checkout before removal; it is not a published artifact. See `docs/cleanup-inventory.md` and `report.md` for counts and scope.

Retained historical receipts are unchanged and do not certify the current architecture. Deleted historical narrative and model manifests can be inspected through Git history when needed; they are not current runtime instructions.

Current legal coverage is documented in `legal/README.md`. `docs/person-tracking.md` and the browser-session guide define independent review/privacy boundaries. Private recordings, reviews, credentials and derived sensitive outputs stay outside Git and published documentation.
