## Cleanup policy and actions

The audit found no tracked private datasets, model weights, image dumps, temporary log files or Python cache binaries. Generated `web/out`, `.next`, environments and private runs are ignored. Verification receipts, legal snapshots, smoke scripts, model manifests and active deployment work remain because build/test/reproduction or historical claims depend on them.

The superseded frontend setup note was moved to `docs/archive/frontend-setup-20261017.md`, with the referring link updated. It has no runtime/build/test import. The old note is historical: the approved UI stack is already implemented. No research or evaluation evidence was discarded because of age.
