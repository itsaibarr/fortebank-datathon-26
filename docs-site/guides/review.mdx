## Try the public interface

1. Open [Forte Review](https://fortebank-review-demo.vercel.app).
2. Choose **Load sample review**. The generated four-second sample, simulated timeline and explicit limitations appear.
3. Select event 2. The video seeks to 0.4 seconds; inspect its source JPEG.
4. Open **Rule conditions**. The sample explicitly has skipped/unavailable rules, not a fabricated legal finding.
5. Open **Human review**, choose a scope and save a note. The demo stores the note in this tab only; reloading clears it.
6. Download the report, or download the sample MOV and try **Browse files → Analyze recording**. Only that exact generated sample is accepted by the simulator.

No account is needed initially. If you test sign-out, the simulated demo sign-in is `demo` / `demo`. These are public demo values, not production credentials. Files and notes are never sent to Vercel or the evaluation VM.

## Real installation

Sign in using your installation's local account. Confirm the displayed destination, readiness, limits and retention notice. Upload one authorized MOV and wait for a terminal result. Inspect the original player beside the event timeline; use evidence and condition tabs before deciding whether any concern is supported.

Use investigation filters to narrow by text, participant, assessment, review presence or time. The filter does not alter the original result or repair missing coverage. A complete report includes original analysis, coverage and review history.

## Independent review scopes

Human corrections append immutable revisions. Visible facts, participant continuity, geometry, roles and legal assessment are separate. A role mapping is not a complete role interval; repeated role words do not approve a temporal join. Preserve uncertainty and null reflection ownership where unresolved.

## Verify

The public generated workflow is browser-checked for seeking, JPEG loading, correction controls and mobile width. Real semantic correctness requires local review of the actual authorized recording, under its source/date/applicability constraints.

## Troubleshooting

If a real upload is unavailable, recheck readiness and the exact HTTPS origin. If the source or frame fails integrity checks, do not substitute another image. If saving a correction conflicts, reload history and append to the current head.

Correction storage and later inference consumption are separate. Automatic
reviewed-correction replay remains unimplemented; saving a revision does not
prove a new analysis used it.
