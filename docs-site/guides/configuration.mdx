The application reads process environment variables. It does not automatically load a `.env` file. Export values in your shell or pass a controlled environment to your service manager. Use `.env.example` as a reference, not as a credential store.

## API process

| Variable | Actual behavior |
| --- | --- |
| `FORTE_API_KEY_FILE` | Read the private service key from this file if `FORTE_API_KEY` is unset. Preferred. |
| `FORTE_API_KEY` | Direct ASCII key, minimum 16 characters; takes precedence over the key file. Do not put it in docs or browser assets. |
| `FORTE_PRIVATE_ROOT` | Persistent private jobs; default `~/.local/share/forte26/jobs`. Use an absolute path outside Git. |
| `FORTE_MODEL_URL` | Resident model origin; default `http://127.0.0.1:8001`. |
| `FORTE_MODEL_NAME` | Served model name; default `forte-vlm`. |
| `FORTE_MODEL_REVISION` | Readiness identity; default pinned baseline8b revision. Must match the actual selected model. |
| `FORTE_MAX_CONTEXT_TOKENS` | API context setting; default 8192. Container entrypoint chooses 16384 for frozen27b. |
| `FORTE_REASONING_CONFIG` | Path to explicit frozen reasoning JSON. The example uses container mount paths; adapt them in a private copy. |
| `FORTE_V1_PIPELINE` | `legacy` by default; explicit `reasoning` additionally requires a reasoning configuration. |
| `FORTE_TRUSTED_GATEWAY_TOKEN_FILE` | Optional separate 32–256 character token. Enables trusted-principal enforcement. A service key alone then cannot call the core. |
| `FORTE_FRONTEND_ROOT` | Optional path to the built static export. Does not create browser sessions. |

## Container entrypoint

`FORTE_MODEL_PATH`, `FORTE_API_KEY_FILE` and `FORTE_PRIVATE_ROOT` are required by `scripts/container-entrypoint.sh`. `FORTE_MODEL_PROFILE` chooses `baseline8b` or `frozen27b`. Frozen27b also requires `FORTE_REASONING_CONFIG`. The script verifies hashes, starts vLLM, checks visual warmup, then starts the API. These variables do not download assets or grant network isolation by themselves.

## Frozen reasoning configuration

`configs/frozen-inference.json` declares detector/ReID resources, legal release/cards, model identity and execution budgets. Defaults include 24 visual calls, 80,000 cumulative tokens, three reinspections and two legal calls. The serving context is 16,384 tokens with sixteen images per call and one active model sequence. An execution budget is a cap, not a guarantee of complete coverage.

Keep `event_date` null unless authorized metadata establishes a reliable recording date. Unknown institution scope or edition applicability must remain unknown. All twelve current operational interpretations are drafts; changing a JSON flag is not human approval.

## Storage and secrets

Keep originals, evidence, corrections, logs, keys and backups outside the repository. Retention is manual. Never mount a cloud-provider credential into the application. Public model/corpus acquisition and private inference are distinct stages. See [authentication](/api/authentication).
