Forte Review helps a reviewer inspect possible cash-operation issues in a video. It connects anonymous participant proposals and a chronological visual timeline to original source frames and a scoped local collection of Kazakhstan regulations. A result is assistance for human review, not a finding of liability.

The selected technique is frozen Qwen3-VL-8B visual facts, mandatory local CPU
Laya three-state condition proposals, and deterministic applicability, evidence,
verdicts and explanation templates. The pinned architecture source and its `report.md` are named in
[installation](/guides/installation). Publishing these guides does not deploy the
application or replace the earlier runtime on `main`.

## What is implemented

- MOV validation, authenticated asynchronous admission, bounded processing and explicit failures.
- Frozen Qwen3-VL-8B visual facts, mandatory local CPU Laya condition proposals and deterministic decisions.
- Recording-local participant proposals and full-duration scheduling with explicit coverage gaps.
- Original presentation timestamps, source hashes and original decoded JPEG evidence.
- Separate execution status and evidence assessment in v2; the exact binary jury v1 contract is retained.
- Exact local legal references, condition findings, explicit unknowns and skipped rules.
- A session-based review workspace with video seeking, evidence, filters and immutable correction history.

## What is live

| Surface | Actual status |
| --- | --- |
| Vercel frontend | Public generated-data UI demo. Processing and sessions are simulated in the tab. |
| Real inference service | Requires a prepared, authorized local CUDA host and verified model resources. No public inference URL/key is published by these docs. |
| Recognition and legal accuracy | Not accepted. Existing runs include failures, partial coverage and insufficient evidence. |
| Reproducibility | Source checks and synthetic API examples can be reproduced without competition data; private semantic evaluation needs authorized inputs and references. |

The demo never uploads selected files or notes. It accepts its generated sample for simulated processing; it cannot analyze your own video. See [limitations](/evaluation/limitations) before interpreting any result.
